# Zehraan Couture — Luxury Pakistani E-Commerce Storefront

An exquisite, production-grade e-commerce application crafted for a luxury Pakistani fashion house specializing in handcrafted festive lawn, luxury pret, unstitched couture, and bespoke wedding formals.

---

## ✨ Features

- **Pakistani Sartorial Customization & Stitching:**
  - **Unstitched 3-Piece:** Complete raw fabric with detailed breakdown of inclusions (embroidered front, organza dupatta, cambric trouser, daman patches, and tassels).
  - **Stitched Ready-to-Wear:** Standard sizes (XS, S, M, L, XL) with inner lining, piping, and professional overlocking.
  - **Custom Bespoke Stitching:** Customer measurement inputs (Length, Bust, Waist, Hips, Shoulder, Sleeve length) and silhouette selector (*Straight Cigarette Pants, Flared Gharara, Classic Shalwar, Tulip Shalwar, Culottes*).
- **Interactive Sizing Guide:** Standard Pakistani size table in both inches and centimeters with measuring guidance.
- **Dynamic Multi-Currency Switcher:** Seamless real-time currency conversion between **PKR (₨)**, **USD ($)**, **GBP (£)**, **AED**, **CAD**, and **SAR**.
- **Catalog & Intelligent Filters:** Filter by category (*Festive Lawn, Luxury Pret, Unstitched, Wedding Formals, Velvet Edit*), fabric (*Pure Lawn, Raw Silk, Micro Velvet, Crinkle Chiffon*), or search by SKU/technique.
- **Slide-Out Bag & Pakistani Checkout Experience:**
  - Real-time cart calculation with free nationwide delivery progress bar.
  - Promo code discounts (e.g. `EID26` for 10% off).
  - Cash on Delivery (COD) across all cities in Pakistan (*Karachi, Lahore, Islamabad, Rawalpindi, Faisalabad, Multan, Peshawar, etc.*).
  - Debit/Credit Cards and JazzCash / EasyPaisa / Raast mobile wallet support.
- **Order Tracking & WhatsApp Concierge:** Instant order reference generation, delivery ETA, and direct one-click WhatsApp concierge inquiry.
- **Heritage Atelier & Lookbook:** Highlighting 400 years of Subcontinental *zardozi, marori tilla, dabka, and adda frame* craftsmanship in Lahore's walled city.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** Motion
- **Build Tool:** Vite

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/minahilsaleem2053/ecommerce_store.git
cd ecommerce_store
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Visit `http://localhost:3000` or `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
```
